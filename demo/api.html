get /tasks List all tasks ▾

Retrieves a list of all tasks.

Responses

200 A successful response containing an array of tasks.
application/json
{
  "items": {
    "$ref": "#/components/schemas/Task"

  "type": "array"
}

post /tasks Create a new task ▾

Adds a new task to the management list.

Request Body required

application/json
{
  "$ref": "#/components/schemas/NewTask"
}

Responses

201 Task created successfully.
application/json
{
  "$ref": "#/components/schemas/Task"
}
400 Invalid input data.
delete /tasks/{id} Delete a task ▾

Removes a specific task by its unique ID.

Parameters

NameInTypeReqDescription
idpathstring✓The unique identifier of the task to delete.

Responses

204 Task deleted successfully. No content returned.
404 Task not found.
500 Internal server error.
